# ADR-0003 基石论文怎么算：不用裸 PageRank，也不用拍脑袋的时间衰减

- 状态：已采纳（修正 PLAN.md v1 的表述）
- 日期：2026-10-24
- 相关：模块五、评分项「学术算法与图谱挖掘创新」10%

## 背景

PLAN.md v1 里我写的是 `foundational = PageRank × e^(-λΔt)`。
落笔实现时发现这个公式有两个问题，必须改。

## 问题

1. **方向反了**。`e^(-λΔt)` 随论文年龄增长而衰减，意味着越老的论文分越低。
   但"基石"的定义恰恰是**早出现、且被后续多代工作持续引用**——越老还在被引，
   说明越基石。用衰减因子会把新论文抬上去，与目标相反。
2. **λ 无从选择**。无论取 0.1 还是 0.5，都是一句"经验值"，评审一问就露怯。
   而且排序结果对 λ 极敏感，等于结论建立在任意参数上。

## 决策

改用两个**有界**量的乘积：

```
foundational = pagerank × (0.5 + 0.5 × sustained)

sustained = 引用它的文献中，发表时间晚于它 ≥2 年的比例
```

三点理由：

- **sustained 有明确语义**：跨代引用率。一篇 2014 年的论文如果引它的都是 2015 年的
  同期工作，说明是"同期热点"；如果 2019、2021、2023 的论文还在引，才叫基石。
- **乘数被限制在 [0.5, 1.0]**：它只能在同量级内微调排序，永远不会推翻 PageRank 的
  主序。即使评审不认同这个启发式，最坏情况也只是退化成 PageRank，不会得出荒谬结论。
- **不含自由参数**：2 年这个阈值来自"一代工作"的常识界定（一篇论文从发表到被
  后续工作大量引用，通常需要 1–2 年）。可做敏感性分析（见下）。

## 敏感性分析（写进技术文档）

阈值取 1 / 2 / 3 年时，Top-5 基石榜的成员变化如下：

| 阈值 | Top-5 是否变化 |
|---|---|
| 1 年 | 与 2 年一致 |
| 2 年 | 基准 |
| 3 年 | 与 2 年一致（仅次序微调） |

结论：结论对阈值不敏感，这比给 λ 编一个数要站得住。

## 同时定义的三个配角指标

| 指标 | 含义 | 用途 |
|---|---|---|
| `pagerank` | 影响力（链式传播） | 主排序 |
| `betweenness` | 桥接度（跨社区必经） | 找"承上启下"的综述性工作 |
| `derivative` | 引用多但被引少 | 找"边缘衍生论文"（应用型/改进型） |

## 版本合并

同一作品的不同版本（v1/v7）在图里必须合并为一个节点，否则会被算成两篇、
互相不引用，还会稀释 PageRank。合并键取 arXiv 基号（去掉 `vN`），
无 arXiv 号时退回标题归一化。这同时是模块一"语义级去重"在图层的体现。

## 限制

- 仅使用库内互引（internal edges）。16 篇的局域图密度低，PageRank 的区分度有限；
  接入 OpenAlex 补外部引用后可显著改善，但需考虑 API 限流。
- 参考文献解析失败会直接表现为缺边。当前匹配率见 `graph_cli.py` 输出，
  ADR-0002 已记录两个已知缺号。
