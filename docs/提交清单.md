## 七、常见疑问

**Q：评审打不开 `http://1.12.228.44:3000` 怎么办？**
先自己 `curl.exe http://1.12.228.44:3000/api/health`，返回 `{"ok":true,...}` 说明服务活着，
问题在对方网络；返回超时则说明服务器或防火墙有问题，按 `部署手册.md` 第十节排查。

**Q：能不能用之前的 Cloudflare 隧道地址？**
不能。那些地址已失效，且每次重启都变，不要写进任何材料。

**Q：视频一定要 B 站吗？**
表单要求"可公开访问的视频平台"，B 站/抖音都行，**网盘链接会被判不合格**。
