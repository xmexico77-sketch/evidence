## 二、代码仓库（已推送）

已推送到 **https://github.com/xmexico77-sketch/evidence**（public，main 分支，47 次提交）。
作者信息目前是占位值 `Evidence Dev <dev@evidence.local>`，需要连同历史一起改写。

### 三步

**第 1 步：在 GitHub 网页新建空仓库**

- 名字随意（如 `evidence`）
- **不要**勾选 "Add a README file"、".gitignore"、license（否则首推会冲突）
- 建好后复制仓库地址

**第 2 步：执行推送脚本**

```powershell
cd D:\deepseek\ai4s
powershell -ExecutionPolicy Bypass -File scripts\push_github.ps1 `
  -RepoUrl https://github.com/<你的账号>/<仓库名>.git `
  -Email <你的 GitHub 邮箱>
```

脚本会依次：设置作者 → 把 41 次提交的作者统一改写 →
清掉 filter-branch 备份 → 配置 remote → `push -u origin main`。
作者名默认「彭嘉荣」，可用 `-Name` 覆盖；不想改历史作者加 `-NoRewrite`。

**第 3 步：首次推送要登录**

用户名填 GitHub 账号，**密码位置填 Personal Access Token**（不是账号密码）。
Token 在 GitHub → Settings → Developer settings → Personal access tokens，
勾 `repo` 权限即可。推送完可以立刻删掉这个 Token。

### 推送后核对

```powershell
git remote -v                      # 指向你的仓库
git log --format="%an <%ae>" | Sort-Object -Unique   # 应为 彭嘉荣 <你的邮箱>
git rev-list --count HEAD          # 41
git status --short                 # 应为空
```

再到网页上确认：仓库是 Public、提交历史完整、README 能正常渲染（含六张截图）。

> `.env` / `.env.local` / `data/` / `*.mp4` / `.cache/` 都在 `.gitignore` 里，
> 密钥、语料、密码文件不会外泄。仓库里只有 `.env.example` 模板。

## 六、演示视频

### 需要你做的

1. 对着 `docs/演示视频脚本.md` 的旁白稿录音（普通话，5–8 分钟）
2. 把音频文件放进项目目录，例如 `讲解.m4a`

### 我这边一条命令出片

```powershell
.venv\Scripts\python.exe scripts\build_video.py --audio 讲解.m4a --out docs\演示视频.mp4
# 只想看时间分配：
.venv\Scripts\python.exe scripts\build_video.py --audio 讲解.m4a --dry-run
```

成片规格：1920×1080 / 30fps / H.264 + AAC，9 个镜头按音频长度自动分配时长。

### 或者实拍（更自然）

按分镜表用录屏软件实拍，注意：

- 分辨率 1920×1080，浏览器缩放 100%
- 先跑 `scripts/demo_rehearsal.py`，15/15 通过再开录
- 提前预热：图谱综述（首次 88 秒）、向量模型（约 6 秒）

## 九、常见问题

**Q：提交后还能改吗？**
以赛事通知为准。通常截止前可重复提交，截止后不可。

**Q：视频必须真人出镜吗？**
赛题要求"普通话讲解"，未强制出镜。录屏 + 旁白即可。

**Q：评审期服务要一直开吗？**
是。这是选云主机而非家里机器的原因——两个多月的持续可用性。

**Q：没有 DeepSeek Key 能演示吗？**
能，但会降级为抽取式：翻译返回未启用、综述为结构式、写作输出提纲而非正文。
当前会话已配置 Key（`.env.local`），部署时把 Key 写进服务器环境变量即可。
