## 五、怎么把本机环境跑起来

只在本机开发、不需要公网时（免登录）：

```powershell
cd D:\deepseek\ai4s

# 后端（端口 8000）
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --app-dir backend

# 前端（端口 3001；3000 被占用时用这个）
cd web; & "D:\deepseek\github工具使用与下载\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe" node_modules\next\dist\bin\next start -p 3001
```

一键启动脚本：`scripts/start.ps1`。

> 服务没起时 `verify_all.py` 会把相关检查标为"跳过"而不是"失败"。
> 看到跳过先确认服务在跑，别当成代码问题。
