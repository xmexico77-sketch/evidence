# 换视频与重传网盘 · 三步清单

> 背景：演示视频刚加了 Agent 轨迹镜头（5:10 → **5:21**），B 站与网盘里还是旧版。
> 本文只做一件事：让视频与网盘和当前材料对齐。**约 20 分钟**。

---

## 第 1 步：B 站替换视频（约 10 分钟）

打开 <https://member.bilibili.com/platform/upload-manager/article> → 稿件管理 → 找到
`证源 Evidence｜…` 那条 → **编辑**。

| 操作 | 说明 |
|---|---|
| 更换视频源 | 上传 `D:\deepseek\ai4s\docs\演示视频.mp4`（10.05 MB / 5:21 / 1080p） |
| 标题 / 简介 / 封面 | **不要动**，沿用原来的 |
| 保存 | 等转码 + 审核（通常几分钟到几小时） |

**要确认两件事**：

1. **BV 号没变** —— 编辑投稿换源不会换 BV，地址仍是
   `https://www.bilibili.com/video/BV1Dcxy66EnQ/`，表单第 ⑦ 项不用改。
2. 时长显示 **05:21**（旧的是 05:10），说明新版本生效了。

> 如果 B 站不让换源、只能重投：会拿到新 BV 号。**把新链接发我**，
> 我改材料里的链接，你改表单第 ⑦ 项。

**审核期间别急着改网盘**——如果视频被退回，网盘还得再传一次。

---

## 第 2 步：网盘重传（约 10 分钟）

新建一个文件夹，名字带上日期（如 `证源Evidence-20261115`），避免和旧文件混淆。

从 `D:\deepseek\ai4s\docs\提交包\` 拖这 **4 个**：

| 文件 | 大小 | 说明 |
|---|---|---|
| `作品介绍.pdf` | 0.5 MB | 表单第 ⑥ 项上传的就是这个 |
| `证源Evidence-技术文档.pdf` | 1.18 MB | 21 页（含新增的 Agent 章节） |
| `演示视频.mp4` | 10.05 MB | 与 B 站同一版 |
| `证源Evidence-作品包.zip` | 20.41 MB | 四件打包（若只传一个文件，传它） |

传完 → 生成分享链接 → **设置长期有效 + 记下提取码**。

**两个提醒**：

- 夸克 / 百度网盘的分享**下载**通常要求登录。为了不被卡住，表单第 ⑤ 项建议同时写上
  仓库地址：`https://github.com/xmexico77-sketch/evidence`（源码免登录可看）。
- 旧文件夹先别删，等新链接验证通过、表单提交成功后再清理。

---

## 第 3 步：回填与复核（约 5 分钟）

| 位置 | 换成 |
|---|---|
| 表单第 ⑤ 项 | 新的网盘链接（含提取码）+ 仓库地址 |
| 表单第 ⑦ 项 | **BV 号没变就不用改**；重投过则换成新链接 |
| `docs/提交清单.md` 第三节 | 新网盘链接（如果你告诉我，我来改） |

然后把链接发我，我做三件事：

1. `curl` 验网盘分享页是否匿名可打开（夸克分享页会返回 200，但下载要登录，这点我会如实说明）；
2. 用无痕方式访问 B 站，确认新视频可匿名播放、时长是 5:21；
3. 跑一遍 `check_deploy.py`（10 项）与 `check_docs.py`（12 项），确认没被这次改动带坏。
