# 证源 Evidence

> 带**段落级锚点溯源**的科研助手 Agent —— 每个结论都能点回原文的页与坐标。

参赛作品 · 第九届传智杯「AI 大模型创新应用挑战赛」· 智领科研·意图驱动

---

## 一句话定位

不是"给 PDF 加个聊天框"，而是一个会自己检索文献、建索引、画引用图谱、写初稿，
并且**每句结论都可回溯到原文某页某段**的科研 Agent。

全系统只围绕一条主线：**确定性**。学术界不用 AI 的唯一理由是不敢信，
所以"抗幻觉"在这里不是提示词技巧，而是三道工程约束：

| 层次 | 机制 | 防的是什么 |
|---|---|---|
| 生成约束 | 强制模型输出 `[E1]` 形式的证据标记 | 无来源的断言 |
| 服务端校验 | 标记必须在证据范围内，否则判不可信、重写一次、仍不合格则拒答 | 模型编造引用 |
| 相关性闸门 | 最高证据重排分 < 0 时直接拒答 | **答非所问但格式合法** |

第三道是最容易被忽略的：锚点能证明"这段文字来自原文"，不能证明"这段文字回答了问题"。
实测问"作者获得过几次图灵奖"时，系统会把作者列表配上完全合法的锚点返回——
标注校验全绿但答案是错的。所以必须有相关性闸门。

## 六大模块实现情况

| 模块 | 能力 | 验收脚本 |
|---|---|---|
| 一 · 解析与去重 | 字符级双栏重建、标题树、表格、公式、扫描件 OCR、语义去重与版本合并 | `verify_parse.py` |
| 二 · 抗幻觉 RAG | BM25 + 稠密向量 → RRF → 多语言 CrossEncoder 重排；三道抗幻觉约束 | `verify_retrieval.py`、`test_antihallucination.py` |
| 三 · 阅读与双语 | PDF.js 原版式渲染、标题树导航、引用深链高亮、锚点对齐的双语联动滚动 | 页面验证 |
| 四 · 发现与推荐 | arXiv 检索/追踪、GitHub 可复现性加权、OpenAlex 引用数、一键下钻入库 | `verify_discovery.py` |
| 五 · 图谱与综述 | 引用网络、时间衰减基石分、Louvain 社区、自动综述、Idea 考古 | `verify_graph.py`、`verify_futurework.py` |
| 六 · 写作与可视化 | CSV → 学术图表（自动选型、量纲分轴）、图注提炼、可复现脚本、TikZ 输出 | `verify_charts.py` |

## 快速开始

### 方式一：Docker Compose（推荐）

```bash
cp .env.example .env      # 填入 DEEPSEEK_API_KEY 与 EVIDENCE_SECRET
docker compose up -d
```

- 前端 http://localhost:3000
- 后端文档 http://localhost:8000/docs
- 首次启动会下载约 640MB 的向量与重排模型（已挂在 `evidence-cache` 卷上，只需一次）

### 方式二：本地运行

```bash
# 1. 后端
python -m venv .venv
.venv/Scripts/pip install -r backend/requirements.txt   # Windows
# source .venv/bin/activate && pip install -r backend/requirements.txt  # Linux

# 2. 前端
cd web && pnpm install && cd ..

# 3. 配置
cp .env.example .env.local

# 4. 一键启动
pwsh -File scripts/start.ps1
```

启动后：

| 地址 | 说明 |
|---|---|
| http://127.0.0.1:3000 | 工作台（问答） |
| http://127.0.0.1:3000/graph | 引用图谱与自动综述 |
| http://127.0.0.1:3000/discover | 论文发现与推荐 |
| http://127.0.0.1:8000/docs | 接口文档 |

## 环境变量

见 [`.env.example`](.env.example)。关键项：

| 变量 | 必填 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | 是 | 唯一的外部模型密钥；未配置时系统退化为抽取式替身（功能可用、效果打折） |
| `EVIDENCE_SECRET` | 是 | 会话签名密钥 |
| `AUTH_ENABLED` | 否 | `1` 启用登录（默认），`0` 关闭 |
| `EVIDENCE_USERS` | 否 | `用户名:密码` 列表，逗号分隔 |
| `HF_ENDPOINT` | 否 | 国内网络建议 `https://hf-mirror.com` |

**密钥只经环境变量进入进程**，仓库里只有 `.env.example`。

## 已知限制

如实记录，避免过度声称：

- **未配置模型时**：翻译、多文对比、综述叙述化、Idea 判定、写作框架退化为
  抽取式/结构式输出。系统会明确标注"未启用模型"，不伪造结果。
- **引用解析**：参考文献实体消解依赖标题匹配，个别缺号（如 v1 的 37/38）会少边。
- **图谱规模**：当前为库内局域图（16 篇），接入 OpenAlex 外部边后可扩展。
- **Docker 镜像**：已提供 Dockerfile 与 compose，但开发机未安装 Docker，
  **未做镜像级验证**；逻辑与依赖组合已在本地虚拟环境实测。
- **认证**：密码明文存于环境变量，无哈希/锁定/轮换，属演示级方案。
